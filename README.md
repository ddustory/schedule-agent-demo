# 내 일정 비서 · 공개 체험판

구글 캘린더 기록을 읽어 **일정 등록 · 하루 계획 · 할 일 정리 · 강의 출석 관리 · 생활 패턴 분석**을 돕는 개인 일정 비서 에이전트의 **공개 체험판**입니다.

> 이 체험판의 일정은 모두 **지어낸 가짜 예시**입니다. 실제로 쓰는 버전은 진짜 일정이 들어 있어 비공개 저장소에서 따로 운영합니다.

## 에이전트가 일하는 방식

말로 요청하면 비서가 **스스로 도구를 골라 여러 단계로** 처리하고, 어떤 도구를 왜 썼는지 **'과정 보기'** 에서 보여줍니다.

```
"다음 주 화요일 7시 친구랑 저녁"
→ 📅 날짜·시간 계산 (AI가 짐작하지 않고 코드로: 10월 20일 화요일, '저녁'이라 오후 7시)
→ 🔍 겹침 확인 → ⛔ 학원 수업(18:00~21:00)과 겹침 경고
→ 🔔 알림 제안 (약속: 2시간 전 + 이동 시간 고려한 출발 알림)
→ ✋ 등록 제안만 만들고, 사용자가 '네, 등록'을 눌러야 실제로 등록
```

## 해 볼 것

| 화면 | 해 볼 말 / 할 일 |
|---|---|
| 비서 | "다음 주 화요일 7시 친구랑 저녁", "내일 계획 짜줘", "내 패턴 분석해줘", "할 일 정리" |
| 일간 · 주간 · 월간 | 예시 일정을 시간표와 달력으로 보기 |
| 출석 | 대학 강의별 결석 횟수와 F까지 남은 횟수 |
| 내 패턴 | 수업 요일·시간, 대타 빈도, 책 대출~반납 기간, 일정이 자주 바뀌는 때 |
| 변경 기록 | 비서가 바꾼 내용 기록과 되돌리기 |

## 안전장치

- 캘린더는 사용자가 **'네'를 눌러야만** 바뀝니다. 삭제는 한 번 더 확인합니다.
- 날짜·시간이 애매하면("7시"가 오전인지 오후인지) 짐작하지 않고 되묻습니다.
- 바꾼 내용은 모두 기록되고 **되돌리기**로 취소할 수 있습니다.
- 분석 결과에서 다른 사람 이름은 가립니다.
- 실제 버전은 노트북 안에서 도는 AI(로컬 모델)로도 동작해 일정이 밖으로 나가지 않게 할 수 있습니다.

## 체험판에서 다른 점

- 방문자마다 따로 시험되고(브라우저별), 서버가 다시 켜지면 시험한 내용은 사라집니다.
- 내 캘린더 올리기, 캐릭터 그림 넣기, 설정 저장은 막아 두었습니다.
- 두뇌는 '규칙 기반'으로 동작합니다. (서버에 AI 모델이 없기 때문)

## 직접 켜기

```bash
python3 -m schedule_agent.server --public-demo --port 8765   # 체험판
python3 -m unittest discover tests                           # 테스트
```
